# Public-IEP-Knowledge-Base-
A public repository of Individualized Education Program (IEP) examples and templates organized by state, with additional international references.
I created this repository after seeing during my internships how difficult it could be to find different IEP examples in one place. The goal is to make IEP research and drafting more efficient while also creating an organized collection that can support the development and evaluation of AI tools for special education.
Because IEP forms and requirements change over time, the repository also includes links to relevant public resources for each state and internationally.
